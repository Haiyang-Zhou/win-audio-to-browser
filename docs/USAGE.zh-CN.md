# 使用说明

[English usage guide](USAGE.en.md) · [中英文项目说明](../README.md)

## 推荐使用 Codex 部署

建议在 Windows 发送电脑上，用 Codex 打开仓库并使用
[README 中的中英文部署提示词](../README.md)。
让它先检查环境、按项目依赖安装、运行测试，再报告接收设备的访问地址。
这是可选的部署方式，不是运行声音传输所必需的软件。
管理员授权、证书警告和麦克风权限等步骤仍需由你确认或完成；不要让它
为图方便关闭防火墙、公开端口或覆盖设备记录。

## 日常操作

双击 `start.cmd` 打开控制窗，点击蓝色按钮开启或停止音频服务。
黄色“−”最小化到任务栏，红色“×”收起到托盘，均不停止声音。
托盘右键可选择保留服务退出，或停止传输并退出。
独占全屏游戏可能覆盖置顶窗口，可改用无边框窗口模式。

右上角“⋯”可选择语言、缩放、右下角停靠及自动命名。
语言会保存并由接收网页约每两秒同步，切换时不重建音频连接。
名称本身不进入编辑；仅点击小铅笔进入，回车或失去焦点保存，Esc 取消。

单台可识别设备连接时改名，会记到它的浏览器标识上；离线或多台设备
连接时只修改窗口名称。同一 Safari/Chrome、同一地址下重连会恢复名字。
设备记录默认位于 `data/device-names.json`，网页语言位于
`data/ui-preferences.json`。桌面窗口偏好由 Qt 保存到 Windows 用户设置。

## 接收设备

与发送电脑连接同一路由器，不要使用启用客户端隔离的访客网络。
用浏览器打开控制窗显示的 `https://电脑地址:8787`，选择“聆听”。
没有声音时检查电脑默认输出设备、播放器音量和接收设备音量。
切换电脑音频输出设备后，应停止并重新启动音频服务。
Windows 系统静音可能同时让采集的声音静音；避免用系统静音消除双重声音，
可以调低实体音箱自己的音量。

播放缓冲仅是浏览器接收缓冲，不能当作端到端延迟。
默认不提供后台/锁屏持续播放保证，建议页面保持前台。
默认先以设备自带扬声器测试，蓝牙耳机通常会增加额外延迟。

## 麦克风模式

断开聆听后可切换麦克风模式。浏览器需要 HTTPS 和用户的麦克风授权。
声音默认播放到电脑输出设备；若希望聊天软件将它识别成麦克风，另需
自行安装并配置虚拟音频线。不要在音箱和麦克风相邻时制造反馈回路。

## 防火墙

不要关闭防火墙。先确认所在网络可信，再按需以管理员身份运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/configure_firewall.ps1 -InterfaceAlias "WLAN"
```

将 `WLAN` 替换为实际网卡名称。脚本只为当前项目虚拟环境的 Python
开放该接口上的私有网络、本地子网入站 TCP 8787 和 WebRTC UDP。
它不会将公共网络改成专用网络，不会替你修改路由器或建立公网映射。
如果 Windows 将网络标为公共网络，规则不会在该配置文件上生效；
仅在确认网络可信后，才由你决定是否调整网络类别。

## 开发命令

```powershell
.venv\Scripts\python.exe app/server.py --host 127.0.0.1 --port 8787
.venv\Scripts\python.exe app/server.py --list-devices
.venv\Scripts\python.exe scripts/verify_audio.py --host 127.0.0.1 --port 8787
```

第一条只供本机访问。手动使用局域网 IP 绑定时，请填写电脑实际地址。
验证脚本会短暂播放测试音，并测量音频帧节奏。
可设置 `AUDIO_LINK_DATA_DIR` 将运行记录迁移到其他可写目录。
